# Part 2 | VS Code Extensions

[Back to start](README.md)

The Windows or Mac helper installs missing ESLint and Prettier extensions. The settings below are the same on both computers. Keep settings that are already correct.

1. Open **Settings** from the Manage menu at the lower left.
2. Search for **Default Formatter** and select **Prettier - Code formatter**.
3. Search for **Format On Save** and enable it.

**Done:** Both extensions show as installed. Prettier is the default formatter and Format On Save is enabled.

If an extension is missing, use [manual extension setup](HELP.md#install-extensions-manually).
