# Part 2 | VS Code Extensions

[Back to start](README.md)

The steps are the same on Windows and Mac. Keep extensions that are already installed.

1. In VS Code, open **View > Extensions**.
2. Search for **ESLint** by **Microsoft** and select **Install**.
3. Search for **Prettier - Code formatter** by **Prettier** and select **Install**.
4. Open **Settings** from the Manage menu at the lower left. Search for **Default Formatter** and select **Prettier - Code formatter**.
5. Search for **Format On Save** and enable it.

**Done:** Both extensions show as installed. Prettier is the default formatter and Format On Save is enabled.

The ESLint extension uses the ESLint configuration in your project. A new Next.js app can include that configuration when you create it.
